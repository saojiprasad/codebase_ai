# Example Repositories To Try

Small first-run repositories:

- `https://github.com/tiangolo/fastapi`
- `https://github.com/pallets/flask`
- `https://github.com/tastejs/todomvc`
- `https://github.com/gothinkster/realworld`

Larger repositories once the local model and embeddings are working:

- `https://github.com/microsoft/vscode`
- `https://github.com/vercel/next.js`
- `https://github.com/facebook/react`

For very large repositories, increase memory, use a smaller embedding model, and keep `ACE_MAX_INDEX_FILES` conservative.
